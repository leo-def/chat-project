# AI Agent Configuration for Chat Project

> Configuration and capabilities for AI-assisted Android development.

## 🤖 Agent Capabilities

### Code Understanding
- **Kotlin**: Modern syntax, null safety, coroutines, extension functions
- **Android SDK**: Activities, Fragments, Services, Intents, Permissions
- **Firebase**: Real-time Database, Authentication, Cloud Messaging
- **MVVM Architecture**: ViewModels, LiveData, Observer pattern
- **Material Design**: UI components, theming, animations
- **Gradle**: Build configuration, dependency management

### Development Tasks Agent Can Perform

✅ **Can Help With**:
- Creating Firebase-backed screens and fragments
- Implementing ViewModel with LiveData
- Building Repository layer for Firebase abstraction
- Creating RecyclerView adapters with Firebase data
- Implementing Firebase Authentication flows
- Writing Unit tests with Mockito
- Implementing real-time listeners for messages
- Building Material Design UI layouts
- Handling Firebase errors and exceptions
- Implementing navigation between screens
- Performance optimization for list rendering

❌ **Not Recommended**:
- Direct Firebase calls in UI layer (use Repository)
- Blocking/synchronous Firebase operations
- Bypassing authentication checks
- Hardcoding Firebase credentials
- Changes to Firebase database schema without migration

## 🛠 Recommended Skills

### Skill 1: Firebase Authentication Integration
**When**: Setting up user login/signup
**Process**:
1. Initialize Firebase Auth in Application
2. Create AuthRepository with signup/login methods
3. Create AuthViewModel for state management
4. Build login UI with email/password fields
5. Handle auth state changes and token storage

### Skill 2: Real-time Message Loading
**When**: Displaying live chat messages
**Process**:
1. Create ChatRepository with Firebase listener
2. Set up message RecyclerView with adapter
3. Implement ViewModel with LiveData<List<Message>>
4. Add Firebase ValueEventListener to messages
5. Update LiveData on data changes, UI auto-updates

### Skill 3: Fragment and ViewModel Communication
**When**: Wiring UI to state and data
**Process**:
1. Create ViewModel in Fragment using ViewModelProvider
2. Observe LiveData in Fragment
3. Dispatch user actions to ViewModel methods
4. Handle loading/error states in UI
5. Implement proper lifecycle awareness

---

## 🔑 Key Concepts

- **MVVM**: Separation of concerns with reactive binding
- **Firebase Real-time DB**: NoSQL with automatic synchronization
- **LiveData**: Observable data holder aware of lifecycle
- **Repository Pattern**: Abstraction over data sources
- **Kotlin Coroutines**: Async operations without callbacks
- **Material Design 3**: Modern Android UI standards

## 📁 File References

- Activities: `app/src/main/java/.../activities/`
- Fragments: `app/src/main/java/.../ui/fragments/`
- ViewModels: `app/src/main/java/.../viewmodel/`
- Repositories: `app/src/main/java/.../repository/`
- Models: `app/src/main/java/.../model/`
- Layouts: `app/src/main/res/layout/`
- Configuration: `app/build.gradle`, `AndroidManifest.xml`
